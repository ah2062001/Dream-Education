# Dream Education

**A Django-based educational management platform for teachers and administrators.**

Dream Education is a web application developed using Python and Django to streamline student management, class scheduling, academic assessments, and reporting.

## Key Features

- **Teacher Dashboard** — Centralized interface for managing teaching activities.
- **Student Management** — Student records, profiles, and subject classification.
- **Class Scheduling** — Calendar-based scheduling and class updates.
- **Academic Reporting** — Student assessments and customized PDF reports.
- **Google Sheets Integration** — Synchronization of student and scheduling information.
- **Administration** — Administrative dashboard and management interfaces.

## Tech Stack

**Backend:** Python, Django  
**Frontend:** HTML, CSS, Django Templates  
**Database:** Django ORM  
**Integrations:** Google Sheets, PDF Reporting
